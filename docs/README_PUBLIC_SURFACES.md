# Public Surface Hierarchy

The Hands Gifted public website should read in this order of importance:

1. **Children & Learning** — children are the center of the development vision.
2. **Hands Gifted Skills** — Cooking, Gardening, Braiding, Sewing.
3. **Family Resources** — household, stability, wellness, and community-resource support around the child.
4. **Bible & Faith** — Scripture integrated through the learning and skill architecture.
5. **Products** — original Hands Gifted creations that go beyond the free information layer.
6. **Book / Services** — direct work a visitor can request from Hands Gifted, labeled by actual readiness.

The website should not expose complete proprietary materials merely to demonstrate value. Public pages teach enough to help and build trust; complete original systems and creations remain products or member resources when ready.
