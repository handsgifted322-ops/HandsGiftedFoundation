# V2 Parallel Build Tracks

The V2 reconstruction proceeds in parallel while production remains protected.

1. **Personal UI** — Personal workspace, Content Readiness, Teach Me/Research, Evidence/Portfolio.
2. **Data Inventory** — map projects, tasks, programs, source artifacts, operating knowledge, Academy resources and other existing tables.
3. **Provenance** — preserve original source, visibility, review state, evidence relationship and derivative/publication history.
4. **Authorization** — Personal, Family, Public, Shared Knowledge/Evidence and System/Internal remain separate scopes.
5. **Research** — evidence types remain epistemically distinct; research can produce reviewed Family lessons or Public derivatives.
6. **Family / Enhanced Gifted** — connect approved research/projects to family learning without granting access to owner-private material.
7. **Public Publishing** — only explicit PUBLIC + approved/published derivatives reach public routes.
8. **Deployment / Verification** — every V2 commit gets preview verification before any production promotion.

The additive `v2_inventory_items` migration is a draft only. RLS policies are intentionally withheld until existing identity/role behavior is verified. Production schema must not be changed merely to make the preview look complete.
